BEDMI LIGHT — CREATOR UNIVERSE

Đây là nền tảng demo tạo và chơi mini game 2D chạy trên trình duyệt.

TÍNH NĂNG ĐÃ CÓ:
- Trang chủ, Explore, Creator Studio và trang chơi game.
- Game Studio: đặt block, platform, coin, xóa ô trên lưới 16x10.
- Đặt tên game, chọn theme, lưu dự án trong localStorage.
- Play Test với nhân vật di chuyển bằng A/D hoặc phím mũi tên, Space để nhảy.
- Game mẫu Sky Jump, Neon Rush, Lost Maze.
- Chat UI demo trong game và Studio.

CHẠY LOCAL:
Giải nén, giữ nguyên thư mục assets, mở index.html bằng Chrome/Edge.
Để dùng tốt nhất, chạy qua Live Server hoặc một static web host.

GITHUB PAGES:
Upload TOÀN BỘ nội dung trong thư mục này vào root của repository.
Sau đó Settings > Pages > Deploy from a branch > main > /(root) > Save.

GIỚI HẠN QUAN TRỌNG:
GitHub Pages chỉ host frontend tĩnh. Bản này lưu dự án và chat demo trong trình duyệt hiện tại; người dùng khác không tự thấy nội dung đó.
Muốn có tài khoản, lưu game online, publish game cho cộng đồng, multiplayer và chat thời gian thực cần backend riêng (ví dụ Firebase hoặc Supabase), xác thực người dùng, cơ sở dữ liệu và hệ thống kiểm duyệt/báo cáo chat. Không đưa secret key quản trị vào mã frontend.
